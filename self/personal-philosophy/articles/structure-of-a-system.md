# Structure of a System

`PP_STRUCTURE` · [← Personal Philosophy](../index.md)

The claim that metaphysics → epistemology → ethics → politics → aesthetics, each branch resting on the one before.

## Questions

- Does my ethics actually follow from my metaphysics, or did I reach both separately and assume they fit?
- Which branch is doing the most load-bearing work?
- Can a system be modular — swap one branch, keep the rest?
- Is aesthetics an output of the system or an input that quietly shaped it?
- If two branches conflict, which gives way?

## Challenges & perspectives

- Free-standing ethics: morality needs no metaphysical foundation at all.
- Coherentism: no branch is foundational, they hold each other up.
- The dependency may run backwards — people pick metaphysics that licenses the ethics they already wanted.
- Systematicity itself is suspect: consistency can be bought by ignoring hard cases.
