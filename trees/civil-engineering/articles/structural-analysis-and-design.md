# Structural Analysis & Design

[← Civil Engineering](../index.md) · `CE_STRUCT`

Analysing whole structural systems and sizing members to code. Analysis and
design are genuinely different activities: analysis asks what a given
structure does under a given load, design asks what structure to build
given uncertain loads, and design is the harder and less determinate one.
Load estimation — wind, seismic, live load, load combinations — carries
far more uncertainty than the analysis applied to it, which makes precision
in the analysis somewhat theatrical. Codes encode accumulated failure
experience and are conservative in ways that are not always transparent or
uniformly distributed; LRFD versus allowable-stress design is a real
philosophical difference about where uncertainty is accounted for.
Redundancy, ductility, and avoiding progressive collapse matter more to
real safety than any single member calculation.

## Open questions

- Where does code compliance stop being equivalent to safety, and how would
  an engineer notice a case the code doesn't cover?
- How much precision in analysis is justified when the load estimate is the
  dominant uncertainty?
- Is performance-based design better engineering than prescriptive code, or
  just uncertainty relocated to the modeller?
- What makes a structure robust against the failure nobody modelled, and
  can that be specified rather than left to judgment?
- How do I read a code provision to understand what failure it was written
  in response to?
- Where is engineering judgment doing the real work, and how is that
  transmitted, given that it isn't written down?
