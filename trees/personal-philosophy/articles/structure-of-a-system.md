# Structure of a System

[← Personal Philosophy](../index.md) · `PP_STRUCTURE`

The classical construction runs metaphysics → epistemology → ethics →
politics → aesthetics, each branch supposedly resting on the one before.
Whether that dependency is real is itself contested: some hold that ethics
genuinely requires a metaphysical foundation, others that ethics is
free-standing and the metaphysics is decoration added after the fact. The
question matters practically — if the branches are independent, a
contradiction in one doesn't threaten the others; if they're load-bearing,
it does.

## Open questions

- Does my ethics actually follow from my metaphysics, or did I arrive at
  both separately and assume they fit?
- Which branch is doing the most load-bearing work in what I currently
  believe?
- Can a system be genuinely modular — swap one branch, keep the rest?
- Where does aesthetics sit: an output of the system, or an input that
  quietly shaped the rest?
- If two branches conflict, which one should give way, and on what
  grounds?
